Week 3 Sorting Exercise - Student Version
=========================================

This NetBeans project contains TODO sections for Week 3 sorting algorithms.

Topics covered:
- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort
- Comparison of time complexity

Instructions:
1. Open this folder in NetBeans.
2. Open the source files inside src/week3sorting.
3. Complete the TODO sections in:
   - BubbleSort.java
   - SelectionSort.java
   - InsertionSort.java
   - MergeSort.java
   - QuickSort.java
   - ComplexityTable.java
4. Run MainApp.java.
5. Check that each algorithm sorts the data in ascending order and shows Sorted? true.

Do not copy from the tutor version. Use it only after submission or when your tutor allows it.
