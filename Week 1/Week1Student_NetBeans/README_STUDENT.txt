Week 1 Student NetBeans Project
===============================

Scenario
--------
You are completing a small Course Management System for a DSA course.

Week 1 topics covered
---------------------
1. Classes and objects
2. Encapsulation
3. Abstract class
4. Interface
5. Inheritance
6. Polymorphism
7. Abstract Data Type (ADT)
8. Fixed-size arrays
9. Dynamic arrays using ArrayList

Main class
----------
week1student.Week1StudentExercise

Files to complete
-----------------
- Week1StudentExercise.java
- Course.java
- Student.java
- Instructor.java
- ArrayCourseList.java
- ArrayListCourseList.java

Supporting files
----------------
- Displayable.java
- Person.java
- CourseListADT.java

What you need to do
-------------------
Complete all TODO sections. You should:
1. Create Student and Instructor objects.
2. Store them in a Person array to demonstrate polymorphism.
3. Validate the Course credit hours using encapsulation.
4. Complete getRole() in Student and Instructor.
5. Implement add, search, remove, size, isFull, and display behavior through CourseListADT.
6. Compare the fixed-size array implementation with the dynamic ArrayList implementation.
7. Run the project and check that the output is logical.

Do not change the method names or class names. Only complete the TODO sections.
